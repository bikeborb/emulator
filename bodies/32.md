### perf(core_timing): wake the timing thread only for a new earliest event

ScheduleEvent and ScheduleLoopingEvent woke the timing thread for every
new event. The thread sleeps until the earliest queued event and handles
everything due when it wakes, so only a new earliest event needs to
wake it. Half of the wakes were for later events; a guest polling with
very short svcSleepThread calls causes tens of thousands a second.
