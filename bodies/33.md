### fix(vulkan): keep custom border colours on Turnip within the sampler budget

VK_EXT_custom_border_color was turned off on Turnip as broken. Mesa's
tu_sampler.cc takes the first free of maxCustomBorderColorSamplers
slots with only an assert, and every sampler took a slot whether its
colour was custom or not. Now only a colour Vulkan has no enum for
takes custom border slots, at most the queried
maxCustomBorderColorSamplers are handed out (4 per Sampler, never given
back), and the first sampler refused is logged; after that samplers use
the nearest standard colour. Turnip keeps the extension; the Qualcomm
driver keeps the removal.

### perf(vulkan): keep BGR and RGB images apart on Turnip

For a mutable image whose format list is not one UBWC class, Turnip
disables UBWC, and when the list holds a format with a component swap
(B8G8R8A8 is one) or there is no list, it stores the image linear
(tu_image.cc, format_list_has_swaps, force_linear_tile). Every RGBA8
image had B8G8R8A8 in its list, so every one was linear.

TextureCacheRuntime::HasNativeBgr() is false on Turnip, and the view
lists and the DMA linear lookup use it, so BGR and RGB are separate
images there and a BGR view of an RGB image goes through the existing
copy path. The present frame gets a two-entry format list, or no
MUTABLE flag when image and view format are the same.

Odyssey on an AYN Thor, same save, alternating builds: 54.8, 54.3 fps
without, 60.6, 58.0 with.

### perf(vulkan): narrow image view format lists so drivers keep compression

Images were created with every format they might be viewed as. For an
A8B8G8R8 image that is 17 formats, R32, R16G16 and A2B10G10R10
included. A driver keeps framebuffer compression only if all formats in
the list compress alike; Turnip disables UBWC otherwise (tu_image.cc,
"Disabling UBWC ... due to mutable formats"; for the Adreno 740 the
A8B8G8R8 UNORM, SRGB, SNORM, UINT and SINT views are one class,
freedreno_ubwc.h). So every RGBA8 render target and texture was
uncompressed.

An image is now created with a narrow list: the formats with its own
component layout. The first time a view needs a format outside it (a
sampled or render target view in FindOrEmplaceImageView, a typed storage
view in FillImageViews), the image is made again with the full list and
its contents are copied over, and its views are dropped as for a
rescale. The replaced image is kept until the GPU and the delayed view
destruction are done with it. Blits prepare both images before looking
up their views.

Super Mario Galaxy boot on an AYN Thor (Turnip's perf log): 39 RGBA8
images had UBWC disabled before this change, 0 after. In gameplay that
ran at 41-46 fps with the Adreno 90% busy at 680 MHz, it now holds
60 fps with the Adreno 46% busy at 615 MHz (the two measured in
different sessions).
