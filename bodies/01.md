### fix(android): stop the force max clock thread from spinning

On Android TurboMode::Run only calls adrenotools_set_turbo(true), which
opens /dev/kgsl-3d0, sets KGSL_PROP_PWRCTRL and closes it again. The
wait at the bottom of the loop only blocks once no frame has been
submitted for a while, so during play the loop never sleeps and repeats
that open, ioctl, close as fast as it can.

With "Force maximum clocks" on, that thread takes most of a core. It
has no name, so it shows up in top as a second "NativeEmulation". On a
Snapdragon 8 Gen 2 (AYN Thor) it sat at 60 to 100% of a core while a
game was running.

The property is set on the device and is only put back by the
adrenotools_set_turbo(false) after the loop, so setting it once a
second is enough. The thread is named TurboMode so it can be told
apart.
