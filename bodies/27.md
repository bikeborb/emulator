### fix(vulkan): dirty the line width when anti-aliased lines toggle

UpdateLineWidth picks the width by SET_ANTI_ALIASED_LINE, so the
register now marks LineWidth dirty.

### fix(vulkan): compare images with images in DescriptorBankInfo::IsSuperset

IsSuperset compared images with the subset's image buffers, so a bank
without storage images could be taken for one with them. Test in
src/tests/video_core/descriptor_bank.cpp.

### fix(vulkan): pick the depth bias representation from DEPTH_FORMAT_DEPENDENT

SET_DEPTH_BIAS_CONTROL DEPTH_FORMAT_DEPENDENT picks the unit of the
constant depth bias: TRUE is the depth format's own least representable
value, FALSE forces the UNORM one (clb197.h). The rasterizer always
asked for FORCE_UNORM. NVK maps the two to the matching
VK_EXT_depth_bias_control representations; the register now does so
here and dirties DepthBias. Drivers without the extension are not
affected.

### fix(vulkan): draw line loops as line strips

Vulkan has no line loop. A triangle list drew filled triangles from
line vertices; a line strip draws every edge but the closing one. The
closing edge needs an index conversion like the one for quads.

### fix(vulkan): drop draws whose pipeline failed to build

A pipeline whose build failed binds nothing (GraphicsPipeline::
ConfigureDraw), but its draws were still recorded and ran with the
previously bound pipeline. The draw commands now check
GraphicsPipeline::IsFailed on the worker thread, where an async build
is known to have failed.

### fix(vulkan): nearest sampling for formats without linear filtering

Turnip cannot filter 32-bit float formats linearly, and a linear
sampler paired with such a view is undefined. A view records whether
its format has SAMPLED_IMAGE_FILTER_LINEAR, and PushImageDescriptors
uses the sampler's nearest variant when it does not, as it already did
for integer formats.

### fix(vulkan): narrow vertex attributes that run past their stride

Maxwell fetches each vertex attribute by itself, so a game may declare
one that runs past its binding's stride (Tears of the Kingdom: 16-bit
float x4 in a 6-byte stride). Vulkan needs it to fit
(VUID-vkCmdBindVertexBuffers2-pStrides-06209). VertexFormat takes the
bytes available and drops components of the guest's own layout until
it fits (x4 to x3 to x2 to x1); the shader reads the dropped ones as
0, 0, 1. A host fallback that widens a format is left alone. Used by the
dynamic vertex input path and by pipelines; the first such layout per
type and size is logged.
