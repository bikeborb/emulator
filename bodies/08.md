### fix(core): do not make the 2 GB device memory table resident at startup

With a 39-bit device address space the DeviceMemoryManager entry table is 2 GB. The constructor
wrote an initial value into every entry, which made all of it resident in every game. The
table is left zeroed now and a continuity of zero reads as one.

Red Dead Redemption on an 11.4 GB device: anonymous memory 2,646 MB to 555 MB in game, memory
left for the rest of the system 2.0 GB to 3.6 GB.
