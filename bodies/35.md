### feat(qt): Run with AOT (experimental) through ScarletNX on Windows

Adds "Run with AOT (experimental)" to the game list context menu of XCI,
NSP and NRO entries on Windows. It hands the dump to ScarletNX
(https://github.com/scarletnx/ScarletNX), a static ARM64 to x86
recompiler that extracts the game, recompiles it ahead of time and runs
it on its own runtime. citron does not run the game in this mode.

The first use asks for scarletnx.exe from ScarletNX's Windows zip and
keeps the path in the scarletnx_path UI setting. scarletnx.exe run from
its zip keeps work/ and games/ in its working directory and looks for
prod.keys and title.keys there before %USERPROFILE%\.switch, so it runs
in <citron dir>/scarletnx next to copies of citron's key files. It is a
GUI program, so its standard output and error go to scarletnx.log and
scarletnx-errors.log in that folder.

A progress dialog follows the first run's extraction and recompilation,
which take minutes. citron reads the two logs on a timer instead of
owning the process: ScarletNX runs the game in a job object that ends
it when scarletnx.exe ends, so a child of citron's would close the game
with citron. The dialog follows the lines ScarletNX's own launcher reads
(src/gui/steps.c): "Unpacking ", "Extracting ", "Building hactool",
"Recompiling NAME (", "compiled block N/M" (flushed as printed), "Built "
and the game's first line, "ScarletNX - NAME", which closes it. Stop
ends scarletnx.exe and, through its job object, what it started. If
scarletnx.exe ends before the game starts, the last lines of its error
log are shown.

Nothing from ScarletNX is built or shipped with citron; it is started as
a separate program.
