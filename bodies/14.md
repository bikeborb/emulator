### fix(buffer_cache): give every declared storage buffer a binding slot

The shader recompiler lets a shader declare up to Shader::Info::MAX_SSBOS
(32) storage buffers, but the buffer cache had 16 slots. The compute binder
dropped slots 16 and up while the descriptor update template still had an
entry for every declared buffer, so every later descriptor was read from the
wrong place; the graphics binder had no bounds check and wrote past the
array. The updated DOOM Eternal declares 19 and lost the GPU device about a
minute in on every build. NUM_STORAGE_BUFFERS is now 32 (the enabled and
written masks are u32), with a static_assert at both bind sites so the two
limits cannot drift apart again.

### fix(vulkan): cache failed compute pipelines instead of rebuilding them every dispatch

CurrentComputePipeline only reused a cache entry when it was non-null, so a
compute shader whose build fails was translated again on every dispatch.
The graphics cache already builds only when the entry is new and keeps a
failure as null; compute now does the same. On the Thor, DOOM Eternal went
from 1.1 to 30.7 fps (GPU thread 975 to 213 ms of CPU per second).
