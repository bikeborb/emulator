### perf(maxwell3d): do not mark state dirty on writes that change nothing

Games re-send most of their state before every draw. Marking it dirty each time made every draw
rebind vertex streams and revalidate state. yuzu skipped such writes; the check is restored,
ahead of the Zero Kai render target workaround, which still runs on every write that changes a
render target word.

GPU thread 646 to 602 ms/s and Vulkan worker 310 to 279 ms/s in Red Dead Redemption. Odyssey,
Tears of the Kingdom, DOOM Eternal and Red Dead render the same. If a game shows stale state
after this, look here first.

Review fixes folded in:

Maxwell3D: render target words still go through the Zero Kai layer
check when the value does not change, since the memory behind a target
can be mapped after its registers were written. Other unchanged writes
still return early and mark nothing dirty.
