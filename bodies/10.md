### feat(android): load updates and DLC that sit beside the game

The core can load updates and DLC from folders without installing them
(ExternalContentProvider), but only the desktop frontend fills its folder
list. On Android the game folder is a storage access framework tree, which
the core cannot list, so nothing was ever found there.

When a game starts, the frontend now lists the game's folder, picks the
.nsp files whose title ID is an update or DLC of that game, and hands them
to the provider (SetFiles). Nothing is copied or installed.

AYN Thor, Mario Kart 8 Deluxe: the base game v0 with the update v1441792
beside it starts as version 4.0.0 at 62 fps. The log says "External
content: 1 of 1 update and DLC files opened", and the warning that the
program does not use a 39-bit address space, which the base game alone
gives, is gone.
