### refactor(video_core): flat page tables in the buffer cache and the GPU memory manager

BufferCache::page_table, BufferCache::write_heat and
Tegra::MemoryManager::page_table were Common::MultiLevelPageTable<u32>:
one reserved mapping plus a first-level vector that only recorded which
64 KiB chunk had been touched. On Linux and Android the class already
mapped the whole table up front, so the first level only decided whether
TryGet returned null. They are now Common::VirtualBuffer<u32> of the
same size: entries are read directly, an entry never written reads as 0,
which already meant "no buffer" and "not hot", and SetPageBufferId does
not write an entry that already holds the value.

MemoryManager::PageTableOp keeps its bounds check written out (size != 0
and the range inside the address space) and logs and returns 0 where
ReserveRange used to assert.

MultiLevelPageTable had no other user and is removed.
